# Severity if the test fails
- Critical: remote compromise, auth bypass, full data breach, or RCE with no precondition.
- High: access to other users' data, privilege escalation, stored XSS, or a key/secret exposure.
- Medium: needs user action or a special condition; limited data exposure; weak crypto settings.
- Low: hardening gap, small information leak.
- Info: best practice with no direct exploit.
