# STE100 rules for this project (ASD-STE100, issue 9)
1. Steps: imperative mood, one instruction per sentence, max 20 words. Other sentences: max 25 words.
2. Active voice. Use present tense for facts, future only when needed.
3. One word, one meaning. Use: do, make sure, examine, send, change, use, show, look at, find.
   Do NOT use: perform, ensure, utilize, leverage, verify (use "make sure" or "examine"), attempt (use "try"), obtain (use "get"), via, e.g., i.e., etc.
4. Do not use -ing words as nouns or adjectives. Use the full noun (for example "the test" not "the testing").
5. Keep articles (a, an, the). Do not drop them.
6. Write technical names exactly as in the source (for example "Content-Security-Policy", "HttpOnly", "JWT", "alg:none").
7. Warnings and cautions go before the step they apply to. Say "Do not run on production." in a precondition.
8. No marketing words, no jokes, no idioms. No contractions.
